# Legacy Frontend Files

Esta carpeta contiene pantallas legacy, duplicadas o fuera de ruta movidas desde `src/pages/`.

Reglas:
- No usar estos archivos para nuevas implementaciones.
- No reconectar rutas hacia esta carpeta sin una decisión explícita.
- La superficie activa del sistema sigue en `src/pages/`.
- Si un archivo de aquí sigue siendo necesario, primero debe auditarse y compararse contra la versión activa.
